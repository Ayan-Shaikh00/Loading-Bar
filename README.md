# Loading Bar

A simple and interactive **Loading Bar** built with HTML, CSS, and JavaScript.

The project displays a loading percentage along with a progress bar that gradually increases from **0% to 100%**. Refresh the page to see the loading animation in action.

## 🚀 Live Demo

[View Loading Bar](https://ayan-shaikh00.github.io/Loading-Bar/)

## 📌 Features

* 📊 Loading percentage from 0% to 100%
* 📈 Animated progress bar
* 🔄 Starts automatically when the page loads
* 🎨 Simple and clean UI
* ⚡ Built with vanilla JavaScript
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and loading bar design
* **JavaScript** – Controls the percentage and progress bar animation

## 🧠 What I Learned

* Updating HTML elements using JavaScript
* Dynamically changing numbers with JavaScript
* Controlling the width of an element using JavaScript
* Creating loading/progress animations
* Working with JavaScript timing functions

## 📂 Project Structure

```text
Loading-Bar/
│
├── index.html
├── style.css
└── script.js
```

## 💻 How It Works

When the page loads, JavaScript starts increasing the loading percentage from **0 to 100**.

At the same time, the width of the progress bar increases according to the current percentage, creating a simple loading animation.
